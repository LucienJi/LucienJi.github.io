# Portraits / headshots

Your selfies / headshots. Keep a few styles (e.g. `serious.jpg`, `casual.jpg`) and
switch which one is shown by editing ONE line.

- About-page portrait: `src/content/about/index.mdx` -> `portrait: "portraits/serious.jpg"`
- Reference images by path **relative to `src/assets/`** (e.g. `portraits/casual.jpg`).
- Optimized at build (AVIF/WebP) by astro:assets.
